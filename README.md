# Shuolee 113：现有视频人像重建复现

**本分支 `shuolee/113` 用于从头复现现有视频的 113，固定版本为 `v113.0.0-reproduction`。** 工程通过 Git 上传；在公司电脑 00 使用 WinSCP 连接 Linux 训练服务器，打开 SSH 终端后拉取代码、安装环境、运行训练。

请先读 [113：WinSCP 与服务器训练操作](docs/113_WinSCP与服务器训练.md)。它包含连接参数、Git 授权/克隆、两份输入的上传位置、安装、检查、训练命令、日志和点云下载。对应入口是 `scripts/route113.py all`：175 相机固定、全新几何拟合、20 万初始高斯、18,000 步；不读取以前的人物高斯或优化器。

这是历史实验移植，重影质量未验收，异地服务器尚未实跑。本机核验范围见 [113 核验记录](provenance/route113-validation.json)。代码和文档进 Git；原始输入及授权模板由 WinSCP 单独传送，模型不放 WPS。


## 此次使用范围

- 公司电脑 00 使用 WinSCP 连接服务器；训练命令在服务器 SSH 终端执行。
- 代码从 Git 拉取；现有视频输入和授权模板通过 SFTP 单独上传。
- 从头拟合与训练，使用同一段视频的固定 113 观测，不加载旧人物 checkpoint。
- `main` 分支保留此前的新视频开发路线；本次不要运行 `run.py reconstruct` 或 114 的 `scripts/experiment.py`。
- 原始依赖、许可和移植范围见 [源码与核验范围](docs/113源码与核验范围.md)。
