# Shuolee 人体高斯实验工程

> 历史记录：以下说明保留的是最初 114 实验快照。当前传送约定已更改，模型权重不再放 WPS；请以工程根目录 README.md 和“模型配置.md”为准。新视频主入口为 run.py，本页不是当前默认运行流程。

本工程用于当前 HOVER 175 帧材料的两条**静态全身**路线：`aipixel/GaussianAvatar` 与 `jmaraval/GaussianAvatars_SMPLX`。两者各自重新拟合，20 万初始高斯、18,000 步，使用同一组真实整图相机。没有携带旧人物拟合、高斯或优化器继续训练。

公开 SMPL-X 仓库缺少完整训练入口；`src/avatar_core/scene/smplx_gaussian_model.py` 和运行适配是本地实现。GaussianAvatar 采用官方 stage1 网络与 LBS 的静态适配，前景损失统一，未使用官方 LPIPS 训练日程。因此这里不是完整官方基准复现，也不代表重影问题已解决。

- GitHub 私有仓库：`https://github.com/lizuoshuo-lab/shuolee-portrait`。同步代码、配置、依赖说明。
- WPS：整个 `D:\00` 按你的设置直接同步。人物原图、mask、检测器输出和许可模板留在本工程的 `data/`、`assets/`，均被 Git 忽略。不要将许可模板或人物素材提交到 Git。
- `工作日志/2026-10-25` 保存已有输出；不是新训练的初始化。
- 此工程是现有数据的可迁移实验快照。新视频仍需要独立抽帧、检测、分割与相机估计，不能把当前数据的观测文件套到另一视频。

## 异地服务器取得工程

在服务器用自己的 GitHub 登录授权，然后执行：

```bash
gh auth login --hostname github.com --git-protocol https --web
git clone https://github.com/lizuoshuo-lab/shuolee-portrait.git
cd shuolee-portrait
```

从 WPS 下载本工程的 `data`、`assets` 两个目录，原样放进克隆目录。脚本只通过相对配置定位它们，不要求保留本机的 C 盘路径。先验证文件完整性：

```bash
python scripts/experiment.py audit
```

## 环境

已有训练环境记录为 Linux/WSL、Python 3.10.19、PyTorch 2.7.1+cu128、CUDA 12.8、PyTorch3D 0.7.9、nvdiffrast 0.4.0。服务器需 NVIDIA GPU、匹配驱动和 CUDA 编译工具。不得把本机编译好的 `.so` 复制到不同服务器冒充安装完成。

```bash
python3.10 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip setuptools wheel
python -m pip install torch==2.7.1 torchvision==0.22.1 --index-url https://download.pytorch.org/whl/cu128
python -m pip install -r requirements.txt
python -m pip install --no-build-isolation ./src/avatar_core/submodules/diff-gaussian-rasterization
python -m pip install --no-build-isolation ./src/avatar_core/submodules/simple-knn
python -m pip install --no-build-isolation ./third_party/nvdiffrast
python -m pip install --no-build-isolation ./third_party/pytorch3d
```

首次安装仍需在目标服务器实际编译和 `doctor` 验证；本机的通过不等于异地服务器已部署。`audit` 需要 NumPy 和 Pillow，未建环境时先完成以上安装。CUDA 扩展、PyTorch3D、nvdiffrast 的编译源码随 Git 提供，源码哈希见 `provenance/source-manifest.json`。

## 从头实验的步骤

仅使用 `scripts/experiment.py` 入口。保留源码包含历史默认路径供溯源，入口会在导入前重绑定数据、模型、输出和先验位置，禁止直接运行历史脚本。

```bash
# 输出目录必须不存在；不会覆盖现有实验。
python scripts/experiment.py prepare --run runs/hover175_pair_001
python scripts/experiment.py doctor --run runs/hover175_pair_001

# 第一条路线：拟合和检查
python scripts/experiment.py fit --run runs/hover175_pair_001 --arm gaussianavatar
python scripts/experiment.py review-fit --run runs/hover175_pair_001 --arm gaussianavatar
```

查看 `runs/hover175_pair_001/gaussianavatar/fit/review/` 的原图和投影覆盖图，图片无文字叠加。检查头颈、肩袖、躯干、腿脚是否能作为粗初始化。确认后把同级 `visual-review.json` 中 `usable_as_coarse_static_initialization` 设为 `true`，保留拟合哈希；这不等于质量验收通过。明显错位时停在此处分析。

```bash
python scripts/experiment.py preflight-gaussians --run runs/hover175_pair_001 --arm gaussianavatar
python scripts/experiment.py train --run runs/hover175_pair_001 --arm gaussianavatar
python scripts/experiment.py export --run runs/hover175_pair_001 --arm gaussianavatar
```

第二条路线将 `--arm` 改为 `smplx`，从 `fit` 开始重复上述步骤。两组分别重新拟合，不复制另一组 `fit/fitted.npz`。按顺序执行，一个 GPU 同时只跑一项任务。已有 `current.pt` 的输出拒绝重新启动；本入口不提供跨实验恢复。

训练原生未叠字图片：各组 `gaussian-run/render-*.png`。最终高斯：`gaussian-run/viewer-export/point_cloud.ply`，世界坐标、+Y 向上、完整旋转协方差与 SH；转换或回读不通过时不发布。将其拷贝到 `00/工作日志/日期/点云`，在 `00/工作/查看器` 点击“打开文件”加载，并实际检查 Gaussian 和 points。不要把 `preflight.ply`、局部绑定参数或未通过检查的文件当最终结果。

## 当前证据与限制

当前共享 K、逐帧外参来自 074 COLMAP 估计，并非设备原始标定。训练用 175 个真实相机和 175 个 mask；现有粗拟合沿用 175 帧特征观测，其中原始拟合 mask 只覆盖 59 帧。后续提高拟合 mask 覆盖是独立实验变量，不在打包时悄悄改变算法。

114 两条路线均完成，但重影验收未通过。117 正在区分相机估计、跨视角物理点对应和人物微动；没有得到合格相机前不自动发起下一轮训练。本次整理不启动训练。

上游版本见 `upstream.lock.json`，各原始许可证随源码保留。代码、权重和人体模板的授权分别适用；本工程不重新授予它们的商业许可。
