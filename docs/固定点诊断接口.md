# 固定相机与共享三维点的诊断接口

该接口已经实现三角化和留出视角重投影，`material-tracks`阶段可以自动生成纹理候选；物理材料身份、独立标定验收和人物微动分解尚未完成。当前服务器版本仍停在 `alignment-gate`，无纹理时更早停止。接口输出不能用作手动放行训练的凭据。

## 输入与坐标

`--run` 指向原运行目录，其 `data/training-inputs.json` 中的整图相机、图像路径、尺寸、图像SHA256是唯一相机来源。相机使用刚性的 `w2c`；K保留COLMAP的角点原点约定。轨迹的二维坐标必须在对应的去畸变整图中，以整数为像素中心。投影时减0.5，反投影时加0.5，各一次。原始畸变图或裁剪图的坐标不能直接传入。

`--tracks` 是JSON文件，结构如下。下列数值仅演示字段，不能当作有效实验观测。

```json
{
  "schema": "shuolee-fixed-tracks-v1",
  "pixel_domain": "undistorted_integer_centers",
  "camera_manifest_sha256": "实际相机清单文件的SHA256",
  "camera_fit_observation_ids": null,
  "tracks": [
    {
      "track_id": "texture_0001",
      "identity_basis": "material_candidate",
      "region": "face",
      "triangulation_frames": ["frame_000001", "frame_000003"],
      "observations": [
        {"frame": "frame_000001", "observation_id": "source_feature_1_8", "image_sha256": "对应图像SHA256", "uv": [150.2, 200.8]},
        {"frame": "frame_000002", "observation_id": "source_feature_2_9", "image_sha256": "对应图像SHA256", "uv": [149.1, 201.2]},
        {"frame": "frame_000003", "observation_id": "source_feature_3_4", "image_sha256": "对应图像SHA256", "uv": [147.5, 201.5]}
      ]
    }
  ]
}
```

每条轨迹至少三个不同视角，至少两个预先指定的三角化视角，至少一个留出视角。不得根据计算后哪个残差小再挑三角化视角。`observation_id` 必须能追溯到源图特征，不能因换了匹配方法就把同一观测换编号后算作独立验证；重复编号和同一源像素的不同编号会被拒绝。

`identity_basis` 可为 `material_candidate`、`semantic_landmark`、`unknown`。前者仅声明待核验的真实材料对应，不代表已经验证；鼻尖等检测器编号也不会自动变成材料身份。

`region` 可为 `static_scene_candidate`、`face`、`clothing`、`body`、`unknown`。背景候选中的人物、屏幕、反射、遮挡物还需排除，区域名本身不能证明静止。

`camera_fit_observation_ids` 未知时必须是 `null`；已知时传入相机求解中使用的原始观测编号。出现交集时标记 `not_independent`。没有编号交集也只标记 `id_disjoint_only_unverified`，因为编号完整性、重复物理点、求解链路和实际材料身份仍需核验。不能把空数组当作获得独立性的捷径。

## 计算内容与解释

程序先核对相机清单与每张图像的实际哈希，再按指定视角求一个共享三维点。相机始终固定，不优化K、R、t。其余视角仅将该三维点投影回图像，保存预测位置、观测位置和像素残差。输出每条轨迹，不删除误差大的点以改善统计。

同位置相机、视差不足、点在无穷远和负深度均保留明确原因。默认三角化角度下限1度是实现中的诊断条件，不是实拍物理标定精度的保证。没有可测轨迹时误差统计为空值，不是零误差。

留出视角没有参与该点的三角化，不等于它没参与相机求解。即使残差为零，也不能单独确认焦距正确：平行相机的特殊布局中，焦距与深度可以同时缩放而保持投影不变。相机平移错误与人物位移同样可能产生相同残差。需要独立静止场景、材料身份和相机不确定度证据才能进一步归因。

## 当前验证范围

`scripts/check_fixed_tracks.py` 使用OpenCV独立生成投影，在已有Linux环境验证旋转相机、半像素坐标、留出错配、数据混用、焦距／深度歧义、相机／人物位移歧义、视差退化与文件身份。测试不加载人物权重、不使用GPU、不改历史相机、不提取新的实拍对应，不证明当前视频已经对齐。

## 自动候选的生成与限制

新视频默认流程在人物观测之后执行 `material-tracks`。独立检查某个符合新像素域约定的运行目录时，可用 `python scripts/extract_material_tracks.py --run /data/runs/person_001 --output /data/diagnostics/person_001_tracks`，输出目录必须不存在且在原运行目录外。不要修改历史相机清单字段来绕过缺失的像素域约定。

匹配前保存 `plan.json`，固定源图／mask哈希、源码哈希、OpenCV版本和三视角组合。默认按保留帧的实际顺序使用间隔1、2、4，不插值相机或图像。SIFT默认最多2000个特征，最近邻比例0.75，双向身份一致后才参加三视角闭环；参数写入方案，不根据重投影结果调节。图像与mask边界使用4像素或3倍SIFT尺度的较大支撑距离，是启发式过滤，不是测得的不确定度。

每对匹配的NPZ保留两个方向的最近邻比例及拒绝原因。多个局部闭环合并后，若同一帧出现两个特征身份，整个冲突组件被排除并记录。最终每条候选轨迹用最早和最晚观测三角化，其余视角留出。人体语义点仅可定义面部区域；它们不会替代失败的纹理匹配。

重复纹理、反射、弱纹理皮肤和遮挡仍可能使SIFT失败或产生错误闭环。背景名称仅为候选，检测框漏掉的其他人、屏幕和反射不因此成为静止真值。当前相机先于候选轨迹生成，独立编号不能消除与COLMAP观测的重合，故 `camera_fit_observation_ids` 保持未知，并明确标记未在相机拟合前独立留出。

尚缺：相机求解前的可追溯独立划分与使用记录、真实材料身份核验、静止场景覆盖与相机不确定度评估、人物残差运动检查。上述缺项完成前，不能把此接口包装成已完成的自动对齐系统。
